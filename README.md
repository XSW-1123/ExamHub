# ExamHub — MealNow 面试背题

把《MealNow面试题库（整合版）.docx》里的 **全部内容**（571 道正式题 + 37 张阅读卡，共 608 张卡片）
做成了一个类似"背单词软件"的本地背题网站：SM-2 间隔重复算法（Anki 同源），
纯静态、零依赖、数据不出本机。已接入 PWA，可作为独立应用安装到桌面或手机，断网也能刷题。

## 怎么用

**方式一（推荐）**：双击 `index.html`，用浏览器（Chrome / Edge）打开即可。

**方式二**：双击 `start.bat`（需要本机装了 Python），会启动本地服务并打印本机局域网 IP，
同时自动打开 http://127.0.0.1:8686/ 。手机和电脑连同一 WiFi 时，用打印出的
`http://<本机IP>:8686` 也能打开（首次可能需要在 Windows 防火墙弹窗里允许）。

- 学习进度自动保存在本机浏览器的 localStorage 里，换浏览器 / 换电脑前，
  先到「我的 → 导出进度」备份成 JSON 文件，在新环境「导入进度」即可无缝继续。
- **手机上要「装成 App」不能用方式二**：局域网 `http://192.168.x.x` 不是安全上下文，
  浏览器不会给安装入口。手机请直接访问 https 站点，见下一节。

## 安装为应用（PWA）

PWA 要求 **https**（或 `127.0.0.1`）。所以手机端请用 GitHub Pages 的地址：
`https://xsw-1123.github.io/ExamHub/`，不要用 `file://` 或局域网 http。

| 平台 | 操作 |
|------|------|
| Android（Chrome / Edge） | 打开站点 → 右上角「⋮」→「安装应用」或「添加到主屏幕」；也可点页面底部弹出的安装条 |
| iPhone / iPad（必须 Safari） | 底部「分享」→「添加到主屏幕」→ 右上角「添加」；iOS 没有 `beforeinstallprompt`，只能走这个菜单 |
| 微信 / QQ / 钉钉等内置浏览器 | 装不了。先点右上角「···」→「在浏览器打开」，再按上面两步操作 |
| QQ浏览器 / UC / 夸克 / 华为 / 小米 / vivo / OPPO 等 | 见下一节：它们不做 PWA 安装，本站会明确提示，不再给无效入口 |
| Chrome / Edge（桌面） | 地址栏右侧安装图标，或「我的 → 安装为应用 → 安装 ExamHub」 |

### 为什么 QQ 浏览器、UC、夸克装不了

「安装成独立 App」是**浏览器实现的能力**，不是网站能单方面提供的。Chromium 系里真正做了
PWA 安装的是 Chrome、Edge、Samsung Internet、Opera、Brave；国内主流第三方浏览器
（QQ、UC、夸克、百度、360、华为、小米、vivo、OPPO 自带）都只提供「添加书签 / 快捷方式到桌面」，
点开仍然带着浏览器界面，也不会触发安装事件（`beforeinstallprompt`）。

| 做法 | 效果 |
|------|------|
| 装个 **Edge**（国内应用商店就有）或 Chrome，用它打开站点 → 菜单「安装应用」 | 真正的独立 App：独立窗口、自己的图标、离线可用 |
| 留在 QQ 浏览器：菜单 →「添加书签」勾选「发送至桌面」 | 得到一个桌面快捷方式（用的就是 ExamHub 图标），点开还是浏览器界面；能否离线取决于该浏览器内核是否支持 Service Worker |
| iPhone 上用非 Safari 浏览器 | iOS 只允许 Safari「添加到主屏幕」，其他浏览器做不到 |

本站会识别这些浏览器并在「我的 → 安装为应用」里说明原因，手机首次访问的安装条也会
直接提示「换 Edge / Chrome」，而不是给出点了没反应的假安装按钮。

装好后从桌面 / 主屏图标进入：独立窗口（`display: standalone`）、独立图标、无地址栏；
首次联网打开时 Service Worker 会把整站（含约 1 MB 题库）预缓存，之后地铁上、断网照样能背题。

两个容易踩的点：

- **iOS 装完先别急着导入进度**：主屏图标的存储和 Safari 里是两套，Safari 里背的进度不会自动带过去。
  先在 Safari 里「导出进度」，装好后在应用内「导入进度」。
- **更新要等一次打开**：SW 是「先给缓存、后台拉新」，站点更新后在应用里第二次打开才生效。

> 双击 `index.html` 以 `file://` 打开、或用局域网 http 打开时都不能安装（浏览器安全上下文限制），
> 但页面功能不受影响。


## 功能

| 模块 | 说明 |
|------|------|
| 📅 今日计划 | 到期复习 + 每日新题（默认 20 张/天，可调）。评分：😵忘了 / 🤔模糊 / 🙂记得 / 😎简单，按遗忘曲线自动安排下次复习 |
| 🎯 自由刷题 | 任选一个分类（或全部）顺序/随机刷，不受每日计划限制 |
| ⭐ 收藏夹 | 卡片右上角 ☆ 收藏，可单独成队背诵 |
| 📚 题库 | 全部 608 张卡片浏览 + 全文搜索（标题/题号/正文/来源），点击看详情，可重置单卡进度、手动标记掌握 |
| 📊 统计 | 已掌握数、连续打卡、未来 7 天复习量预测、分类掌握度、近 30 天学习热力图 |
| ⚙️ 我的 | 每日新题数、新题顺序、主题（浅/深/跟随系统）、来源显隐、进度导出/导入/清空 |
| 📲 安装为应用 | 一键触发浏览器安装（PWA）；手机上首次访问会弹出安装条，按平台给出分步说明；独立窗口启动，Service Worker 预缓存全站供离线使用 |

**键盘快捷键**（学习页）：`空格` 翻面 · `1/2/3/4` 评分 · `S` 收藏 · `Esc` 关闭弹层。

## 算法（SM-2，与 Anki 同源）

- 新题/忘了 → 10 分钟后再来；学习中答对 → 明天再见，然后毕业进入长期复习。
- 复习按卡片难易度（EF 因子 1.3~3.2）拉伸间隔：记得 ≈ 间隔×EF，简单再 ×1.35，
  模糊只 ×1.2，忘了间隔打 4 折重学。
- 间隔 ≥ 21 天自动记为"已掌握"。

## 内容完整性保证

网站题库由文档**逐行切片**生成，不做任何删改：

- 解析器按标题边界切卡片，每张卡片 = 原文精确行区间；
- `tools/build_bank.py` 内置"行覆盖校验"：文档 21332 行中所有非标题行
  必须被某张卡片覆盖，否则构建失败；
- `tools/verify_bank.py` 独立二次校验：原文 13716 个非空行逐一反查题库，
  全部命中（标题→标题字段、来源→src 字段、附录A分组→grp 字段、正文→body 字段）。

最终入库：**正式题 528 道（C00~C18 各章，与章节标题标注的数量逐一相符）
+ 附录 A 项目深挖题 43 道 = 571 道；另有第 0 章项目介绍、附录 B/C/D、
文档目录等阅读卡 37 张，合计 608 张。**

## 重建题库（可选）

改了 docx 或想重新生成时：

```bash
python tools/build_bank.py     # 需要已安装 pandoc；会自动重新提取并校验
python tools/verify_bank.py    # 独立复核
```

中间产物落在 `_work/`（已在 `.gitignore` 中忽略），脚本需在项目根目录执行。

## 部署到 GitHub Pages

纯静态站点，无构建步骤，推送到 GitHub 后：

1. 仓库 **Settings → Pages**；
2. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`；
3. 保存后等一分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

`.nojekyll` 已就位，Jekyll 不会改写或忽略任何资源；`data/questions.js`（约 1 MB）
是普通静态文件，不触及 Pages 的体积限制。学习进度仍只存在访问者本机 localStorage。

部署到 https 后即可在浏览器里「安装为应用」。缓存注意两点：

- **改站点文件时必须同步改 `sw.js` 顶部的 `VERSION`**，否则老访客一直用旧缓存；
- 更新策略是「有缓存先给缓存、后台拉新」，所以新版本在访客**第二次打开**时生效；
  调试时可在 DevTools → Application → Service Workers 里勾 Bypass for network 或 Unregister。

## 重建图标（可选）

```bash
python tools/make_icons.py     # 需要 Pillow，仅此脚本依赖
```

从 `IMG_20260130_191935.jpg` 生成 `icons/` 下全套图标：192/512 普通图标、maskable
（裁到中心 80% 再放大填满，保证任意遮罩下人物都在安全区）、180 的 apple-touch-icon
与 32 的 favicon。换源图后重跑一次即可。
